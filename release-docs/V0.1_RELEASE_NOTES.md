# AgentFlow Hub v0.1

发布日期：2026-09-10。Tag `v0.1` 固定到已验收提交 `1d062dfbbd678770b792a0ecdaef8ebed982d1d0`。

V0.1 提供单知识库支付诊断演示：JWT 登录、TXT/MD 上传与 READY 就绪、Agent 配置和两个只读工具绑定、持久化任务执行、RAG 引用、独立最终生成、Trace 回查及 SSE/页面刷新恢复。订单和支付日志来自仓库固定演示数据。

2026-09-09 Release Gate 13/13 通过：前端 76 项测试与构建、19 例受控浏览器回归、后端 185 项重点测试与构建、47 项 PostgreSQL 检查；V48 22 例受控失败/恢复矩阵的 803 项逐例与 3 项全局检查通过。首次取消测试失败及仅修改测试后的复验均保留。

真实 GLM-5.2 + DashScope text-embedding-v4 + Qdrant 主路径的新任务 `2097605938885128193` 完成 RAG、两工具、独立 final、有效引用与刷新/Trace 收敛，存储检查 23/23，通过时实际消耗 5845 tokens。该结果证明固定模型和演示材料的一次运行，不代表统计可靠性或外部支付接入。

已知边界：此 tag 的知识库绑定接口允许 50 个，执行检索上限为 20 个；单知识库验收故事不受影响，21–50 个绑定不保证可执行，后续 V49 修复不包含于此 tag。模型将日志中的“3000ms 后超时”称为“阈值”属于偏强措辞，原始证据保留。进程重启恢复、自动任务重试、多实例执行和多轮对话未纳入 V0.1。

启动步骤见该 tag 的 [README](https://github.com/Xavi-L/AgentFlow-Hub/blob/v0.1/README.md)，逐项证据见 [Release Gate 报告](https://github.com/Xavi-L/AgentFlow-Hub/blob/v0.1/release-docs/V0.1_RELEASE_GATE.md)。本发布说明同步用于 annotated tag 的说明正文。
