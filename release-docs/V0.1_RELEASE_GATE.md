## 判定口径与证据范围

- **PASS**：对应门槛已有可核查实现及匹配的执行证据；注明本轮、历史、受控或真实外部服务边界。
- **PENDING**：本轮计划中的必要检查尚未结束，暂不形成最终结论。
- **FAILED**：已运行检查出现非预期结果；保留失败记录，不用历史成功覆盖。
- **BLOCKED**：缺少依赖、凭据或执行条件；不以 mock 结果替代真实外部服务要求。

[Project Spec §5.1](../spec-docs/agentflow-hub-project-spec.md#51-v01-用户故事) 定义的用户故事是：登录、建立支付知识库、上传 TXT/MD、等待 READY、配置 Agent、绑定**一个知识库和两个只读工具**，诊断 `order_1024`，观察进度并回查答案、引用和 Trace。§5.2 明确首个演示只绑定一个知识库。此次主故事按此范围验收；不将一次固定模型成功推断成任意模型、任意文档或所有资源规模的可靠性。
